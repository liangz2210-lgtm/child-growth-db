## 二、反馈回路（不要写成单向因果）

发展是**循环**的，不是线性的。用回路描述：

```
睡眠不足 → 前额叶调控↓ / 杏仁核反应↑ → 情绪调节↓ → 更难入睡
            ↑                                    │
            └────────────────────────────────────┘
```

**干预策略不是"切断上游"，而是找回路里最容易插入的点。**
按可控性排序：行为层面（流程、规则）> 半可控（时间点）> 生理层面（时长本身）。
