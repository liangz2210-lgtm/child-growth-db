# 指标字典 v2.0

> **唯一的准入规则**：一个指标能进每日采集，必须同时满足两条——
> ① **客观上能查到**（看钟、算时长、看分档），不依赖主观估计；
> ② **单一含义**（不能是几个不同东西的加总）。
>
> 不满足的，一律降频或删除。**不可采集的指标不是指标，是愿望。**

---

## 一、为什么只有三层

```
每日（可查的时刻与次数）  ←  唯一的高频数据
   ↓ 周聚合
每周（可算出的率与稳定性）  ←  不做额外提问，从日数据算
   ↓ 月/季
阶段（能力与体格）        ←  交给儿保与标准化工具，我只做观察框架
```

**核心原则：每日只记「客观事实」，每周只算「能从事实推出的数」，阶段评估交回专业工具。**

## 二、每日采集（3 项必采 + 2 个附属）

| id | 指标 | 单位 | 采集方式 | 为什么是它 |
|---|---|---|---|---|
| `bedtime` | 熄灯时刻 | HH:MM | 看钟 | **最客观的睡眠指标**。不需回忆、不需估计，直接反映作息稳定性 |
| `waketime` | 起床时刻 | HH:MM | 看钟 | 与 bedtime 一起算出夜间睡眠，误差最小 |
| `nap_h` | 午睡时长 | 小时（0.5 精度） | 算 | 唯一能影响入睡时间的白天变量，且部分可控（几点叫醒） |
| `tantrum_lvl` | 发脾气强度档位 | `0`/`1`/`2`/`3+` | 分档报告 | **分档比精确计数更可靠**——回忆"两三次"比"3 次"准确，且降低报告负担 |
| `observer` | 主要照护者 | `p`父母 / `g`照护者B / `o`其他 | 一眼可知 | **没有这个字段，场景对比永远做不了**（见 CRITIQUE 批判六） |

**每日答完 = 报 3 个数 + 一个字母 + 一个档位。30 秒。**

### 明确删掉的（及原因）

| 原指标 | 删除原因 |
|---|---|
| `interact_min`（共读+户外+互动合计） | 复合量，共读与户外机制不同，加总无意义 |
| 「回应性互动次数」 | **不可采集**，没人会数对话轮次 |
| `screen_min` 日采 | 家长普遍低估 30–50%，日采是低质量数据；改周报 + 月度手机统计核对 |
| `new_words_n` 日采 | 新词是离散事件，日采会有大量 0 与回忆误差；改周记「这周新出现的话」 |
| `toilet_ok_n/accident_n` 日采 | 每天才几次，日率无意义；改周成功率 |

## 三、每周（由日数据计算，不额外提问）

| id | 算法 | 意义 | 注意 |
|---|---|---|---|
| `wk_night_sleep_avg` | 周均（waketime − bedtime） | 是否达 10–11h | 跨午夜需正确处理 |
| `wk_bedtime_mean` | 周均熄灯时刻（换算为分钟） | 平均作息 | 不用时:分直接平均 |
| `wk_bedtime_sd` | 熄灯时刻的**标准差**（分钟） | **作息稳定性** | **本库关键指标**：孩子不是被"睡得少"打垮的，是被"睡得乱"打垮的 |
| `wk_tantrum_rate` | 周均 tantrum 档位 | 情绪调节趋势 | **必须按 `observer` 分组看** |
| `wk_data_completeness` | 有效天数 / 7 | 数据质量自检 | <50% 触发降级（见退出条件） |

### 每周一次的低频项（对话里顺口问，不设表）

- **屏幕**：这周平均每天多少分钟（每月用手机「屏幕使用时间」截图核对一次）
- **共读**：这周有几天读了（**记天数不记分钟**——天数比分钟可靠得多）
- **如厕**：这周大概几次成功、几次尿裤子
- **新词**：这周新出现的话（记原话，不计数）

## 四、阶段评估（月/季，交回专业工具）

### 我的角色：观察框架，不是评分

⚠️ **本库不产生任何标准化发育评分。** ASQ-3 有版权、需购买问卷与授权；儿心量表-II 需医生施测。**我无法替你施测，也不假装在施测。**

我做的是：按五能区**设计观察问题**，让你在儿保时能准确描述；保留原始观察供医生判断。

| 能区（ASQ-3 框架） | 观察什么 | 对应儿心量表-II |
|---|---|---|
| 沟通 | 句子长度、提问、理解指令层数 | 语言 |
| 大运动 | 跑跳、上下楼、平衡 | 大运动 |
| 精细运动 | 搭积木、画线画圆、用勺 | 精细动作 |
| 解决问题 | 假装游戏、配对、拼图、数概念 | 适应能力 |
| 个人-社会 | 自理、轮流、共情、情绪表达 | 社会行为 |

### 体格（体检数据）

`ht_cm`、`wt_kg`、`hc_cm` + 血常规（Hb、Ferritin）→ 写入 `reviews/` 月回顾。
参考区间见 `knowledge/growth-reference.md`。

## 五、观测效度机制（v2.0 新增）

v1.0 完全缺失。**没有效度机制的数据，越整齐越危险。**

| 风险 | 表现 | 处置 |
|---|---|---|
| **屏幕低估** | 家长自报普遍低于实际 30–50% | 每月用手机「屏幕使用时间」截图核对，记录偏差率 |
| **社会赞许偏差** | 互动/共读时长被系统性高估 | 不采分钟；只用「天数」（更难虚报） |
| **选择性记录** | 照护者B带娃时无人记录，而那正是 tantrum 高发场景 | `observer` 字段 + **明确声明覆盖缺口，不补不猜** |
| **回忆误差** | 晚间提问需回忆整天 | 只问「可查的时刻」与「分档次数」 |

**分析铁律**：缺失 = 没测，不是 0。不填充、不插值、不推断。

## 六、证据强度标注

| 级别 | 含义 |
|---|---|
| **A** | 系统综述 / Meta 分析 / 多国权威机构指南 / 大样本纵向 + 协变量控制 |
| **B** | 单项 RCT 或大样本队列 |
| **C** | 专家共识 / 权威机构建议但缺直接干预证据 |
| **D** | 理论推导 / 初步研究 |

每条建议落库时标级别。证据更新时倒查，找出需要推翻的结论。

## 七、数据治理

1. **单一数据源**：`data/series.csv` 是纵向数据的唯一真身
2. **不可回溯修改**：更正时追加一行并标 `note:correction`，不覆盖原值
3. **隐私**：不含姓名/住址/机构名，他人用代称
4. **版本化**：建议 `git init` + commit
