# 理论基座 v2.0

> v1.0 的问题是：列了 10 个理论，每个一句话，**彼此并列且会给出相互冲突的建议**。
> 2.0 改成一个**框架**：不问"该听哪个理论"，而问"**这个问题属于哪一层**"。

---

## 一、三层整合框架

任何现象，按顺序过三层。**顺序不可颠倒**——颠倒就是用错层的工具解释问题。

```
第 1 层 · 时间尺度
   这件事是「今天的状态」还是「几年的轨迹」？
   工具：Sameroff 发展级联 + 发展系统理论（Thelen & Smith）
   → 决定：值得干预，还是值得等待
        ↓
第 2 层 · 系统层次
   该改的是孩子、某个成人、还是场景设计？
   工具：Bronfenbrenner 生态系统理论
   → 决定：改谁
        ↓
第 3 层 · 机制
   具体用什么手段让它改变？
   工具：操作性条件反射 + 执行功能模型 + 神经发育时序
   → 决定：怎么做
```

### 为什么这三层能共存而不冲突

因为**它们回答的不是同一个问题**：

| 理论 | 只负责回答 | 属于 |
|---|---|---|
| Erikson 心理社会发展 | 为什么这个阶段特别难（2–3 岁＝自主 vs 羞怯） | 第 1 层的阶段背景 |
| Sameroff 发展级联 | 这件事会传导到哪里 | 第 1 层 |
| 发展系统理论 | 实时互动与发展轨迹如何相互塑造 | 第 1 层 |
| Bronfenbrenner 生态系统 | 该改哪一层环境 | 第 2 层 |
| Skinner 操作性条件反射 | 为什么同一行为在不同人面前频率不同 | 第 3 层 |
| Miyake 执行功能三成分 | 为什么"知道"不等于"做到" | 第 3 层 |
| 神经发育时序 | 为什么讲道理无效（前额叶髓鞘化至 20 岁） | 第 3 层 |
| Bowlby–Ainsworth 依恋 | 回应的"质"为什么重要 | 第 3 层（关系机制） |
| Vygotsky ZPD | 帮助该给在哪个点 | 第 3 层（教学机制） |
| Thomas–Chess 气质 | 为什么同一招对不同孩子效果不同 | 第 3 层的调节变量 |

**冲突消解规则**：不同层给出的建议不冲突，只是分工不同。
同一层内冲突时，按**证据强度**（A>B>C>D）取，不按理论名气取。

### 框架用法示例：他发脾气

```
第 1 层：这是"今天的坏心情"还是"稳定的行为模式"？
  → 数据：在照护者B面前高频、他人面前低频 = 稳定的模式，不是随机情绪
  → 判定：需要干预，不能"等长大就好"

第 2 层：改谁？
  → 微系统成员的行为后果不一致 → 改成人，不改孩子
  → 尤其改"最常被触发的那 1–2 个场景"的边界

第 3 层：用什么手段？
  → Skinner：改变后果（抱而不答应 = 撤除强化但保留关系）
  → 神经发育：发作中不讲道理，只做安全 + 命名情绪
  → 执行功能：不要求他"自己冷静"，提供外部支架（计时器、预告、有限选择）
```

**三层都过完，建议才是完整的。** 只做第 3 层＝头痛医头；只做第 2 层＝换人不换法；只做第 1 层＝空谈等待。

## 二、框架的自我限制（诚实声明）

1. 这是**启发式框架**，不是可计算模型。它不能预测数值
2. 它的价值是**避免用错层**——最常见的错误是用第 3 层手段解决第 1 层问题（"多讲几遍道理"解决一个系统性强化问题）
3. 它**不替代临床判断**。发育异常仍需专业评估

## 三、支持性证据（2025–2026）

每条标注：强度、**改动层级**（结构 / 指标 / 话术）。

> 「改动层级」是 v2.0 新增的自检列。**连续三次只改"话术"，说明检索在空转。**

### N01 · 口语是自我调节的原因，不只是结果
- **来源**：Kia Tīmata Pai / ENRICH 整群 RCT，*Developmental Science* 2026
- **结论**：教师培训提升幼儿口语与自我调节，自我调节效应更强；活性成分是 **responsive turn-taking**（尤其互动式共读）
- **路径**：口语↑ → 能用词汇表达情绪与意图 → 自我调节↑
- **强度**：A
- **改动层级**：**结构**（语言从"语文目标"改为"情绪调节杠杆"；共读从"读几本"改为"有无来有回"）

### N02 · 屏幕的真正机制是机会成本
- **来源**：英国政府 EYSTAG《Screen use by children aged under five》2026
- **结论**：无单一安全阈值的证据；"怎么用"与"用多久"同等重要；互动型风险显著低于被动；30 分钟内被动观看害处有限；**核心机制是挤占真实互动、睡眠与身体活动**
- **强度**：A
- **改动层级**：**结构**（屏幕不再作为独立指标，而作为"挤占变量"——只要睡眠与户外达标，1 小时内不设为独立干预目标）

### N03 · 1.5 小时是风险分界
- **来源**：Gath et al.，*Developmental Psychology* 2026, 62(3)（N=6281，控制家庭背景后仍显著）
- **结论**：2 岁时每日屏幕 >1.5h → 4.5 岁词汇/沟通/书写/计算低于平均、同伴问题高于平均
- **强度**：A
- **改动层级**：指标（确立 1.5h 预警线，用于**周报**而非日采）

### N04 · 「教育类」视频不豁免
- **来源**：广州市妇女儿童医疗中心，*BMC Public Health* 2025（N=2100）
- **结论**：>1h 语言迟缓风险 +49%，剂量反应；样本中 76.43% 看的正是教育类视频，仍无效
- **机制**：屏幕单向输出，不会等回应、不会给表情反馈、不会示范修正。语言长在一来一回里
- **强度**：B
- **改动层级**：话术（M13 纠偏卡）

### N05 · 突触密度 2–3 岁达峰；睡眠不足直接损伤调节系统
- **来源**：杨琳《脑科学视角下的儿童早期发展》，*中国儿童保健杂志* 2025, 33(6): 593–596
- **要点**：突触密度 2–3 岁达峰后修剪；前额叶髓鞘化至 20 岁；**睡眠不足 → 前额叶功能↓ + 杏仁核反应性↑ → 情绪不稳**；睡眠承担髓鞘形成与突触修剪
- **强度**：A（权威综述）
- **改动层级**：结构（为"睡眠↔情绪"反馈回路提供机制，取代原来的单向因果链）

### N06 · 睡眠质量中介亲子关系→执行功能
- **来源**：崔晓晨等，*中国学校卫生* 2025, 46(8): 1166–1169（3 次随访，N=746）
- **结论**：睡眠质量部分中介（依赖型 19.40% / 冲突型 11.22%）
- **强度**：B
- **改动层级**：指标（睡眠上升为 L1 核心，不再只是"健康习惯"）
